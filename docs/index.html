OpenReview 문법 안내

일반 Markdown을 그대로 입력하세요. 수식도 OpenReview와 같은 순서로 처리됩니다.

강조
**bold** · *italic* · ~~strike~~
인용과 목록

- Our response
인라인 수식
$x + y$
여러 줄 수식
$$…$$ · 왼쪽 정렬
수식의 역슬래시
Markdown 처리 후 MathJax가 수식을 읽습니다. $\\frac{a}{b}$처럼 역슬래시를 두 번 써야 Markdown이 역슬래시를 제거하지 않습니다. 원문을 자동으로 수정하지 않습니다.
줄바꿈
새 문단은 빈 줄로 구분합니다. 문장 끝에 공백 두 개를 넣으면 강제 줄바꿈됩니다.
표 · 코드
파이프(|) 표와 백틱 코드 블록을 지원합니다. HTML은 글자로 표시되고 일반 이미지 삽입은 지원하지 않습니다.

렌더링 기준

OpenReview 공식 웹 소스의 Markdown 설정, HTML 정리 규칙, MathJax 설정과 본문 스타일을 사용합니다.

OpenReview web 1.15.42 · 소스 기준 ↗
Marked 15.0.6 · DOMPurify 3.4.17 · MathJax 3.2.2

Markdown이 활성화된 리뷰·댓글 본문을 기준으로 합니다. 실제 사이트의 업데이트, 입력란 설정, 본문 너비와 기기 글꼴에 따라 보이는 모양은 달라질 수 있습니다.

독립적인 미리보기 도구이며 OpenReview에 연결하거나 답변을 제출하지 않습니다. 작성 내용은 서버로 전송하지 않습니다. 같은 브라우저의 여러 탭은 초안 저장 공간을 공유합니다.
