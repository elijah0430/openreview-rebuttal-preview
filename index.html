OpenReview formatting guide

Write standard Markdown. Math is processed in the same order as on OpenReview.

Jump to source
Double-click a word or sentence in the preview to move the Markdown cursor there. Double-click a formula to edit its source. This works with Sync scroll on or off.

Backslashes in math
MathJax reads formulas after Markdown is processed. Use doubled backslashes, as in $\\frac{a}{b}$, to prevent Markdown from removing them. Your text is never changed automatically.
Line breaks
Separate paragraphs with a blank line. Add two spaces at the end of a line for a hard line break.
Tables and code
Pipe (|) tables and fenced code blocks are supported. HTML is shown as text; ordinary image embeds are not supported.

Rendering details

Uses the Markdown settings, HTML sanitization rules, MathJax configuration, and body styles from the official OpenReview web source.
